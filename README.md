# 森野疾行 · Wild Dash

使用 Babylon.js 9、TypeScript 和 Vite 制作的网页 H5 3D 跑酷游戏。场景与角色模型由代码生成，路面使用随项目打包的 ImageGen 贴图，不依赖在线模型、图片或字体服务。

试玩地址：https://mrknowwind.github.io/paoku1/

## 基础玩法

- 三条跑道自动前进，随距离逐渐加速。
- 手机：左右滑动换道、上滑跳跃、下滑滑铲，游戏中没有虚拟方向按钮。
- 电脑：方向键或 WASD，空格跳跃，P / Esc 暂停。
- 木桩需要跳跃，横杆需要滑铲，大石块需要换道。
- 每枚金币加 50 分，每米距离加 2 分；碰撞后结算，可重新挑战。
- 默认简体中文；设置中可切换 English / 日本語 / 한국어，并调整音效及画质。
- 最佳纪录和设置保存在当前浏览器；切到后台自动暂停。
- 设置使用游戏风格语言下拉菜单；首页精简为开始按钮与纪录，详细操作在帮助页查看。
- 首页角色坐在路边树桩上待机，开始后起身走向跑道中央，镜头转为追随视角，完成 3、2、1、GO 倒数后开跑。
- 圆润角色配合膝、踝、肘关节动画；换道采用阻尼过渡，跳跃、滑铲和落地平滑衔接。
- 收集火花、起跳及落地扬尘、碰撞光圈与镜头反馈，配合树冠摆动和飘叶。碰撞后留出短暂动画时间再显示成绩。
- 待机相机固定在跑道内侧，人物附近保留林间空地；两侧树木、灌木和石块使用不规则轮廓及局部材质细节。
- 奔跑使用前倾、屈肘摆臂、后蹬及腾空节奏；跳跃包含收膝与落地缓冲，滑铲采用脚向前的后仰姿势。开场走路保留较慢步频与较小摆幅。
- 成绩页分开展示得分、距离、金币和操作按钮，设置及帮助窗口使用一致的小尺寸图标和排版。

## 本地运行

需要 Node.js 24 或更新版本。

```sh
npm ci
npm run dev
```

打开终端输出的本地地址（默认 http://localhost:5173/paoku1/）。同一 Wi-Fi 下的手机可通过终端输出的局域网地址访问。

```sh
npm test       # 玩法及四语完整性测试
npm run build # TypeScript 检查与生产构建
npm run preview # 预览 dist 中的生产版本
```

## 性能约定

性能优化属于每次实现的完成条件。新增或改动玩法时，同时检查普通跑动、怪物成群、连续命中和爆炸等峰值场景，照顾移动端以及高低两种画质。

- **HUD 和浮字**。血量、库存和武器等在显示值变化时更新。伤害和弹药浮字只在事件触发时从 3D 坐标投影一次，统一由 CSS 用 `transform` 和 `opacity` 上浮淡出，动画结束移除节点。暂停或指南冻结浮字，倒流、回首页和新局清理残留。常驻图标优先使用与显示尺寸匹配的本地 WebP 和简单描边。
- **网格与特效**。共用材质和几何，静态且共享材质或关节的细节可合批。活动角色保持独立动画与点击判定。短生命周期特效优先复用网格并限制池容量与同时发射的粒子数。低画质优先降低粒子密度、场景细节和渲染分辨率，保持预警与判定清楚。
- **帧循环与生命周期**。缓存可复用的节点和数据，按需计算投影、查询和重建。限制缓存、历史与对象池大小，暂停时减少空转，离场、倒流或重开时清理对应状态。沿用已有自适应分辨率，加载时分批准备素材与场景，关注首帧与进入新地形时的尖峰。
- **定位掉帧**。需要实机排查时，在游戏地址加 `?perf=1` 打开性能面板。用同一设备、画质与相近场景对照平均 FPS、P95 帧时、CPU/GPU 耗时、绘制次数和网格数，并留意拾取或命中瞬间。源码发现与实测结论分别记录。本地采样遵循 [AGENTS.md](AGENTS.md) 的验收约定。
- **测试边界**。保留碰撞、伤害、地形可达性、存档与倒流、四语完整性、几何可见性等可观察回归。同一规则合并成参数化测试。CI 通过代表规则和构建检查通过，画面与实际帧率由设备端验收。

## GitHub Pages 自动部署

`.github/workflows/deploy.yml` 在每次推送到 `main` 时自动运行：安装依赖 → 测试 → 构建 → 发布 GitHub Pages。也可在 Actions 页手动运行。

仓库 Settings → Pages → Source 使用 **GitHub Actions**。Vite 的 `base` 已设置为 `/paoku1/`，资源路径适配项目型 Pages 地址。更改仓库名称时需同步修改 `vite.config.ts` 的 `base`。

```sh
git add .
git commit -m "Update game"
git push origin main
```

## 代码位置

- `src/game.ts`：独立的跑酷规则、物理、碰撞、关卡生成。
- `src/scene.ts`：Babylon.js 场景、角色动画与特效。
- `src/props.ts`：不规则木桩、风化岩石、木板横杆、树桩和本地程序纹理。
- `src/motion.ts`：可独立验证的角色动作混合与落地反馈。
- `src/main.ts`：界面、手势、键盘、音效和本地保存。
- `src/i18n.ts`：中英日韩文案。
- `src/style.css`：桌面及手机界面。
- `public/art/woodland-trail.jpg`：本地小径纹理，生成提示词记录在同目录 README 中。

需要支持 WebGL 的现代浏览器。目前为无尽跑酷基础版本，尚未加入账号、联网排行榜或付费系统。

## Codex 工作约定

Codex 修改时默认不执行本地测试、构建验证或浏览器验收，修改完成后提交并推送，由用户验收。GitHub Actions 中的自动测试和部署构建继续保留。具体约定记录在项目根目录 `AGENTS.md`。
